## Summary

My notes lived in Obsidian and my AI work lived in a terminal, and moving between the two broke my flow. Claudsidian connects Claude Code to an Obsidian vault, so I can work with my notes using AI without leaving the place they live.

## What I learned

- The best AI tools fit into a workflow you already have instead of asking you to start a new one.
- Plain Markdown files make a great interface between people and AI: both can read and write them.
- Publishing something I built for myself pushed me to document it properly, and that made it better.
